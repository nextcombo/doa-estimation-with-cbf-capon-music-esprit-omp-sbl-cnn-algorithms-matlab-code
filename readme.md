# DOA Estimation with CBF, Capon, MUSIC, ESPRIT, OMP, SBL, CNN Algorithms [MATLAB Code]

The earliest method for spatial spectrum estimation based on arrays is the conventional beamforming (CBF) method, which essentially is a simple extension of time-domain Fourier spectrum estimation to the spatial domain. The principle is straightforward but its resolution capability is limited and is constrained by the array Rayleigh limit. To enhance the ability to resolve targets, superresolution is necessary, which is an important research direction in spatial spectrum estimation. The most typical methods for superresolution spectrum estimation are the Multiple Signal Classification (MUSIC) method and the Rotationally Invariant Subspace (ESPRIT) method. Both methods rely on the signal subspace and utilize the properties of the signal subspace to achieve superresolution in direction finding. These two types of algorithms require a significant amount of independent identically distributed fast-sampling data, typically requiring several times the number of elements as the number of samples, with the limitation that prior information about the number of targets is required.
This assignment mainly involves the simulation of several spectrum estimation algorithms, including CBF algorithm, Capon algorithm, MUSIC algorithm, ESPRIT algorithm, OMP algorithm, SBL algorithm, and CNN algorithm. Performance comparisons among these seven algorithms are conducted.
